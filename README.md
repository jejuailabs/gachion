# 가치onAI 랜딩페이지

`repo`의 대화 전문, PDF 3종(총 52쪽), 이미지 20장을 검토해 만든 한국어 정적 원페이지 사이트입니다. 원본 자료는 수정하지 않았습니다.

## 로컬 실행

이 폴더에서 `python -m http.server 4173 --bind 127.0.0.1 --directory dist`를 실행한 다음 http://127.0.0.1:4173/ 에 접속합니다. `data.json`을 읽으므로 파일을 더블클릭하지 말고 HTTP 서버를 이용합니다.

빌드·패키지 설치가 필요 없습니다. `dist` 전체를 정적 호스팅에 올리면 됩니다. Vercel에서도 출력 폴더를 `dist`, 프레임워크를 Other로 설정해 사용할 수 있습니다.

## 내용 수정

- `dist/index.html`: 첫 화면, 소개, 실험 원칙, 2기 안내, 문의, 메타데이터
- `dist/data.json`: 활동 연혁, 사진 목록, 서비스 4개, 다음 활동
- `dist/style.css`: 색상, 글자, 반응형 레이아웃
- `dist/main.js`: 목록 렌더링, 메뉴, 사진 확대, 이메일 복사
- `dist/assets`: 제공 사진을 웹용 WebP로 최적화한 이미지

이메일은 `naggu1999@gmail.com`으로 연결했습니다. 문의 종류에 따라 메일 제목이 다릅니다. 메일 작성기를 열며 사이트에서 직접 접수하거나 저장하지 않습니다. 이메일을 바꾸면 `index.html`, `main.js`, `data.json`의 주소를 함께 수정합니다.

## 편집 판단

팀의 실적을 보여주는 온라인 소개 페이지이자 참여·마을교육·협력 문의 창구로 설계했습니다. 이야기 순서는 소개 → 현장 기록 → 결과물 → 다음 활동 → 함께하기입니다.

- 1기 조건인 11명·4주·3팀만 주요 숫자로 사용했습니다. 현재 운영진 인원 또는 4개 공개 서비스가 모두 1기 산출물이라는 의미로 쓰지 않았습니다.
- 170~180명 모임 규모, 누적 교육 인원, 미확인 날짜·성과는 게시하지 않았습니다.
- 정책 예산, 내부 인물 관계, 정치·기관 섭외 논의와 대화 전문은 사이트에 넣지 않았습니다.
- 2기 시작은 포스터 기준 `추석 이후~10월 예정`입니다. 구체적인 주별 흐름은 제공 기획을 요약한 안내이며 일정·장소·참가비는 문의로 확인하도록 명시했습니다.
- 상설 실험실은 구상 중, 책은 출판 기획 중으로 구분했습니다.
- 실명 프로필, 미확정 협력기관 로고, 가상의 후기·제작자·건강정보를 추가하지 않았습니다.
- 서비스 화면은 제공된 캡처입니다. 실시간 화면이나 현재 접속 보장을 뜻하지 않습니다.
- 현장 이미지를 사용했고 AI 일러스트는 사용하지 않았습니다. 자료 전체를 호스팅 폴더에 복사하지 않았습니다.

## 공개 운영 전 갱신할 정보

2기 확정 일정·장소·참가비, 사진별 대외 게시 동의, 서비스 제작자 표기를 확인하면 반영할 수 있습니다. 게시 동의가 이미 확인됐다는 문구는 넣지 않았습니다. Sites 배포는 기본 소유자 전용입니다.

## 검증

`node --check dist/main.js` 및 `node check.mjs`로 구문, 로컬 자산, 앵커, 서비스 주소, 이메일 경로를 검사합니다. 브라우저에서 모바일 메뉴, 갤러리 닫기/포커스 복귀, 이메일 복사와 화면 넘침을 확인합니다.
